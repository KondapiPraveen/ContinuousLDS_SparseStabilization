# ContinuousLDS_SparseStabilization
This repository contains code for my research work on "Sparse Stabilization of  Continuous Time Linear Time Invariant Linear Dynamical Systems".

## Script files to run to generate the plots
 - R1_Diagonal_Matrices.m : To generate the plots the conference paper accepted at European Control Conference 2026 ( ECC 2026)

 - PlotWrapper.m : To generate the plots in the journal paper except for the comparison against other relevant control schemes

 - Comparison.m : To generate the comparison against other relevant control schemes
